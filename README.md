
# Akshay Personal AI Agents

A collection of personal AI agents built using **CrewAI** and **n8n**, designed to automate tasks, manage workflows, and enhance productivity through intelligent, context-aware interactions.

## Overview
This project demonstrates the use of **Agentic AI** to create autonomous agents capable of performing personal and professional tasks. Each agent is designed to handle specific workflows such as scheduling, communication, and data retrieval.

## Features
- Multi-agent orchestration using **CrewAI**
- Automated workflows powered by **n8n**
- Context-aware responses using **Retrieval-Augmented Generation (RAG)**
- Scalable and modular design for adding new agents
- Integration with external APIs and tools



## Use Cases
- Personal assistant for scheduling and reminders  
- Automated task management  
- AI-powered communication and data retrieval
